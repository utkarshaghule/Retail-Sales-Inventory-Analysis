# Dashboard Images

## 1. Overview
This folder contains screenshots of the Retail Sales & Inventory Analysis dashboard created using Microsoft Excel.

## 2. Dashboard Preview
The dashboard presents key retail performance indicators and visualizations to make the analysis easy to understand.

## 3. Dashboard Components
The dashboard includes:
- Total Units Sold
- Total Net Sales
- Total Estimated Profit
- Total Products
- Units Sold by Product Category
- Units Sold by Region
- Monthly Units Sold Trend
- Inventory Status Distribution

## 4. Purpose
These screenshots provide a visual representation of the analysis and help communicate important sales and inventory insights.

## 5. Tool Used
- Microsoft Excel
