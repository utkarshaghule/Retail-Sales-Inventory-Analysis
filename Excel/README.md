# Excel Analysis

## 1. Overview
This folder contains the Excel workbook used for Retail Sales & Inventory Analysis.

## 2. File Information
- **File Name:** `Retail_Sales_Inventory_Analysis.xlsx`
- **Tool:** Microsoft Excel
- **File Format:** `.xlsx`

## 3. Data Preparation
The dataset was imported into Excel and organized into separate worksheets:
- **Raw_Data:** Original dataset.
- **Cleaned_Data:** Prepared dataset used for analysis.

## 4. Calculated Columns
Additional columns were created using Excel formulas:
- Gross Sales
- Discount Amount
- Net Sales
- Estimated Profit
- Profit Margin
- Stock Status

## 5. Analysis Performed
- Sales analysis by product category.
- Regional sales comparison.
- Monthly sales trend analysis.
- Inventory status analysis.
- Product performance analysis.

## 6. Dashboard
The Excel dashboard includes:
- Total Units Sold
- Total Net Sales
- Total Estimated Profit
- Total Products
- Units Sold by Product Category
- Units Sold by Region
- Monthly Units Sold Trend
- Inventory Status Distribution

## 7. Tools and Features
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Analysis

## 8. Purpose
The workbook helps understand retail sales performance, product demand, and inventory levels through data analysis and visual reporting.
