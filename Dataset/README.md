# Dataset

## 1. Project Overview
This folder contains the dataset used for the Retail Sales & Inventory Analysis project. The dataset is used to analyze retail sales performance, product demand, inventory levels, and business trends using Microsoft Excel.

## 2. Dataset Information
- **Dataset Name:** Retail Store Inventory Forecasting Dataset
- **Source:** Kaggle
- **Format:** CSV (Comma-Separated Values)
- **Domain:** Retail Sales and Inventory Management
- **Analysis Tool:** Microsoft Excel

## 3. Dataset Source
The dataset was obtained from Kaggle:

[Retail Store Inventory Forecasting Dataset](https://www.kaggle.com/datasets/anirudhchauhan/retail-store-inventory-forecasting-dataset)

## 4. Dataset Description
The dataset contains retail-related information, including sales, inventory, product categories, store locations, pricing, discounts, and demand forecasts.

It helps analyze product performance, regional sales patterns, inventory availability, and demand trends.

## 5. Key Columns
- **Date:** Date of the recorded data.
- **Store ID:** Unique identifier for each store.
- **Product ID:** Unique identifier for each product.
- **Category:** Product category.
- **Region:** Store's geographical region.
- **Inventory:** Available inventory quantity.
- **Units Sold:** Number of units sold.
- **Units Ordered:** Number of units ordered.
- **Demand Forecast:** Predicted product demand.
- **Price:** Product selling price.
- **Discount:** Discount percentage.
- **Weather Condition:** Weather information.
- **Holiday/Promotion:** Indicates holiday or promotional activity.
- **Competitor Pricing:** Competitor product price.
- **Seasonality:** Seasonal information.

## 6. Dataset Usage
The dataset is used to:
- Analyze sales performance across product categories.
- Compare sales across different regions.
- Identify monthly sales trends.
- Understand inventory availability.
- Analyze product demand and stock levels.
- Calculate sales and estimated profit metrics.

## 7. Data Preparation
The dataset was imported into Microsoft Excel and prepared for analysis. Additional calculated columns were created to support the analysis, including Gross Sales, Discount Amount, Net Sales, Estimated Profit, Profit Margin, and Stock Status.

**Note:** Estimated Profit is based on an assumed cost percentage, not actual product cost data.

## 8. File Details
The original dataset is provided in CSV format. The Excel analysis workbook and dashboard are maintained separately in the `Excel` folder.
